Section 1

Abstract

CartoonForge is a real-time non-photorealistic renderer that runs entirely in the browser as a single WebGL fragment shader. The entire scene — geometry, lighting, shading, and stylization — is computed per-pixel using raymarching over Signed Distance Functions (SDFs). There are no meshes, no rasterization pipeline, and no texture lookups: every visual element is procedural.

The renderer produces five distinct stylization modes — Classic Anime, Comic Book, Ink Sketch, Flat Cel, and Pencil Sketch — all switchable at runtime without shader recompilation. It includes a full orbit camera, multiple scenes, cel-quantized diffuse lighting, screen-space edge detection, living-ink outline animation, halftone shadow stippling, and a hand-drawn pencil stroke effect using spatially jittered edge samples.

Section 2

Technical Approach

Starting Point

We started from scratch with no starter code. The initial commit was an empty repository. All GLSL, the browser harness, and tooling were written during the project. We referenced Inigo Quilez's SDF function library for primitive formulas (sphere, box, torus, cylinder) and his articles on raymarching; the actual GLSL implementation, pipeline architecture, stylization system, and all scenes are original work.

The Raymarching Pipeline

Raymarching (sphere tracing) works by firing one ray per pixel from the camera, then stepping along the ray in increments equal to the minimum distance to any surface in the scene. When the accumulated distance falls below a small epsilon, the ray has hit a surface. The scene is defined by a single function sceneSDF(vec3 p) that returns a vec2(distance, materialID) pair for any point in space.

The pipeline is split across four GLSL files concatenated at load time by the browser harness. Swapping scenes requires replacing only the active scene file; camera and shading modules are scene-independent.

SDF Primitives and CSG

All geometry is built from a shared library of SDF primitives in reference/sdf_primitives.glsl: sphere, box, plane, cylinder, and torus. Scenes compose objects using CSG operators: opUnion, opSmoothUnion (smooth blending), opSubtract, and opIntersect. The Campanile scene (scene_002) uses a tapered box for the shaft, round-box cutouts approximating arched belfry windows, a pyramid-approximated copper cap, and groups of sphere CSG for the Marin hills silhouette.

Surface Normals

Normals are computed via the tetrahedron method — four SDF evaluations at tetrahedral offsets rather than the six required by central differences. This gives slightly better accuracy and saves two SDF calls per pixel, which matters when sceneSDF is expensive (Campanile evaluates ~30 SDF primitives per call).

Camera System

The camera is a spherical-coordinate orbit: azimuth, elevation, and radius are maintained by the JavaScript harness and passed to the shader as uniform vec3 iCamera each frame. The shader converts to Cartesian coordinates and builds a look-at basis matrix. Mouse drag, trackpad pinch, WASD/arrow keys, and Q/E zoom are all handled in JS so the shader itself is stateless. A barrel-distortion lens warp (optional) adds a slight cartoon fisheye feel.

Cel Shading

Standard Lambertian diffuse is computed as usual, then quantized into discrete bands using floor(rawDiffuse * N) / N. The number of bands N varies by preset (2 for Flat Cel, 4 for Classic Anime, 6 for Ink Sketch). A quantized Blinn-Phong specular highlight is added: the specular term is hard-thresholded at 0.5 rather than left smooth, producing the characteristic anime "glint" dot.

The ambient and band-to-color remapping was a key design decision: rather than mapping band 0 directly to black, we remap so that band 0 = ambient × baseColor and the top band = baseColor. This keeps shadow regions colored rather than pure black, which looks better for all NPR styles.

Screen-Space Edge Detection

Edges are detected by firing two additional neighbor rays (one pixel to the right, one pixel up) from each fragment and combining three signals:

  • Silhouette edges — neighbor ray misses the scene entirely while the center ray hits. Gated by surface facing angle to suppress false positives on grazing-angle ground planes.
  • Depth discontinuity — large relative difference between neighbor and center hit distances (|tR − t| / t). Normalizing by hit distance ensures far-away geometry doesn't dominate.
  • Normal divergence — dot product between center and neighbor surface normals falls below 1, revealing creases on curved surfaces like the belfry arches.

A critical bug found during development: the neighbor raymarch was stopping at t = 20 units, but the hills and background objects in scene_002 are at t = 30–80 units. Every pixel seeing the hills returned a "neighbor miss" and fired the silhouette path — painting the entire lower half of the screen black. The fix was raising the edge raymarch limit to t = 120.

Living-Ink Outline Animation

Rather than applying a hard threshold to the edge magnitude, the threshold is perturbed each frame by a layered sinusoidal noise function: 

float livingInk(vec2 fragCoord, float amp) {
    float t  = iTime * 1.8;
    float nx = sin(fragCoord.x * 0.07 + t * 0.9) * 0.5
             + sin(fragCoord.x * 0.13 - t * 1.3) * 0.3;
    float ny = sin(fragCoord.y * 0.07 + t * 1.1) * 0.5
             + sin(fragCoord.y * 0.11 - t * 0.7) * 0.3;
    return (nx + ny) * amp;
}

This makes outlines subtly thicken and thin as they "breathe," giving the impression of a line drawn by hand that moves slightly over time. The amplitude is tuned per preset: high for Ink Sketch (heavy wobble), low for Classic Anime (barely perceptible drift).

Halftone Shadow Stippling

In shadow regions (where diffuse falls below a per-preset threshold), a procedural pattern overlays the surface. The Comic Book preset uses a classic halftone dot grid: dot radius scales with shadow depth so darker regions get denser, larger dots. The Ink Sketch preset uses crosshatch lines at 45° and 135°, with line thickness varying by shadow depth and the cross-hatch second layer appearing only in the deepest shadows.

Runtime Style Preset System

All five styles share a single compiled shader. A uniform float iStylePreset is written by JavaScript each frame and read into a StyleParams struct at the top of the shading function. Every downstream helper (celShade, halftone, computeEdgeRaw) receives the struct as a parameter. Style switching is instantaneous — no recompile, no flash.

This required replacing all compile-time #define constants with runtime struct fields — a significant refactor from our original design which caused a 200–500 ms recompile flash on every style switch.

Pencil Sketch Mode — Jittered Edge Sampling

The Pencil Sketch preset (added after the milestone) takes a different approach to edge rendering. Instead of computing a single edge magnitude and applying a uniform threshold, it fires three spatially jittered edge queries, each with a noise-driven pixel-space offset applied to the neighbor ray directions: 

vec2 jitter1 = vec2(pencilNoise(uv * 2.1 + t),
                    pencilNoise(uv * 1.8 - t * 0.7)) * amp * 6.0;
float e1 = computeEdgeRaw(fragCoord, ro, rd, hitT, jitter1);

Because each sample's neighbor rays point in slightly different directions, they land on different sides of the edge boundary. Some samples detect an edge, others don't — producing natural stroke breakup, varying width, and gaps that mimic the irregular pressure of a pencil. The shading itself is smooth (non-quantized) grayscale diffuse, converting material colors to perceptual luminance using the standard (0.299, 0.587, 0.114) weights.

Key Decisions and What We Learned

  • WebGL 1.0 has no #ifdef. GLSL ES 1.00 (used by getContext('webgl')) does not support #ifndef/#ifdef preprocessor guards. We had wrapped camera.glsl in a guard to prevent double-inclusion — the compiler silently dropped the entire file, leaving iCamera undeclared. Lesson: test with a minimal harness before adding defensive constructs.
  • Edge detection raymarch range must match scene depth. Using a shorter max distance for the neighbor rays than the main raymarch caused false silhouettes on all distant geometry. The fix (matching limits) eliminated the solid-black lower half of scene_002.
  • Depth discontinuity must be normalized. An absolute depth difference |tR − t| * 0.6 produces enormous values on far-away grazing surfaces (ground plane at t=40 with neighbor at t=45 → edge signal of 3.0). Dividing by t makes the signal scale-invariant.
  • Jittering sample positions produces more convincing hand-drawn strokes than threshold perturbation. Perturbing the threshold with noise only roughens the edge boundary; jittering the sample point makes the stroke itself physically wander, skip, and vary in width — much closer to a real pencil line.
Section 3

Results

All five style presets render in real time (60 fps) in Chrome and Firefox on macOS with a discrete GPU. The Campanile scene evaluates ~30 SDF primitives per main ray plus 2 additional neighbor rays per pixel for edge detection, totaling ~90 SDF evaluations per pixel per frame at full resolution.
